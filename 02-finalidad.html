La idea

Un propósito es una meta que todavía no existe

Con para que, a fin de que y con el propósito de que, la meta aún no se ha logrado. Por eso llevan siempre subjuntivo. Pero antes pregunte: ¿cambia el sujeto?

A purpose is a goal not yet reached, so these conjunctions always take the subjunctive — but first ask whether the subject changes.

indicativo subjuntivo infinitivo

Pruébelo

¿Mismo sujeto o sujeto nuevo?

Cambie el interruptor y compare. Flip the switch and compare the two structures.

Compro una bicicleta para ir al campus sin carro.La universidad vende bicicletas para que los estudiantes vayan al campus sin carro.

Yo compro y yo voy: el sujeto no cambia → para + infinitivoLa universidad vende; los estudiantes van: sujeto nuevo → para que + subjuntivo

Uso una botella reutilizable para ahorrar dinero.Mis padres me dan una botella para que yo ahorre dinero.

El mismo sujeto → infinitivoSujeto nuevo → subjuntivo

Cierro la llave para no desperdiciar agua.Cierro la llave para que el agua no se desperdicie.

Yo cierro y yo no desperdicio → infinitivoEl agua es el sujeto nuevo → subjuntivo

Las conjunciones

Tres maneras de decir «para que»

  • para quesubjuntivoso that (la más común)
  • a fin de quesubjuntivoin order that (más formal)
  • con el propósito de quesubjuntivowith the purpose that (formal)

¿Para qué? o ¿por qué? purpose vs. cause

¿Para qué recicla usted? — Para proteger el planeta. (propósito)
¿Por qué recicla usted? — Porque es importante. (causa)

El sujeto no cambia: para ahorrar.

Paso 1

¿Infinitivo o subjuntivo?

Complete con el infinitivo o con el presente de subjuntivo. Complete with the infinitive or the present subjunctive. First ask: is the subject the same or different?

  1. Compro una bicicleta para (ir) al campus sin carro.
  2. Mi profesora explica la regla otra vez para que nosotros (entender) mejor.
  3. El gobierno da dinero a las familias para que (instalar) paneles solares.
  4. Cierro la llave del agua para no (desperdiciar) agua.
  5. Vamos a hacer una campaña a fin de que todos los estudiantes (reciclar).
  6. Mis padres trabajan mucho para que yo (poder) estudiar.
  7. Uso una botella reutilizable para (ahorrar) dinero.
  8. La ciudad va a construir un parque con el propósito de que las familias (tener) un lugar para jugar.
  9. Le mando el informe a usted para que lo (leer) esta noche.

Paso 2

Una las oraciones

Una las dos oraciones con para que. Join each pair into one sentence with para que. The second sentence has a new subject, so use the subjunctive.

  1. El gobierno da dinero. / Las familias instalan paneles solares.
    Ver una respuesta posible

    El gobierno da dinero para que las familias instalen paneles solares.

  2. La ciudad construye ciclovías. / Los estudiantes van a la universidad en bicicleta.
    Ver una respuesta posible

    La ciudad construye ciclovías para que los estudiantes vayan a la universidad en bicicleta.

  3. Mi profesor publica los materiales. / Nosotros estudiamos antes del examen.
    Ver una respuesta posible

    Mi profesor publica los materiales para que nosotros estudiemos antes del examen.

  4. Los vecinos organizan una limpieza del río. / Los niños tienen un lugar limpio para jugar.
    Ver una respuesta posible

    Los vecinos organizan una limpieza del río para que los niños tengan un lugar limpio para jugar.

Paso 3

Termine las oraciones

Termine cada oración con un propósito original. Finish each sentence with an original purpose. Use a new subject and the subjunctive.

  1. Yo reciclo para que …
    Ver una respuesta posible

    Yo reciclo para que mi ciudad esté más limpia.

  2. La universidad ofrece becas para que …
    Ver una respuesta posible

    La universidad ofrece becas para que todos los estudiantes puedan estudiar.

  3. Mis padres trabajan para que …
    Ver una respuesta posible

    Mis padres trabajan para que yo tenga una buena educación.

  4. El alcalde construye parques a fin de que …
    Ver una respuesta posible

    El alcalde construye parques a fin de que las familias pasen tiempo al aire libre.

Resumen

Lo que debe recordar

  • para que, a fin de que, con el propósito de que → siempre subjuntivo.
  • Mismo sujeto → para + infinitivo. Sujeto nuevo → para que + subjuntivo.
  • ¿Para qué? pregunta el propósito. ¿Por qué? pregunta la causa.
